## 📖 Overview

AI IDE is a modern coding platform designed to improve developer productivity through AI-assisted coding workflows. It provides a clean interface, code editing capabilities, project management, and intelligent code suggestions.

### ✨ Key Features

- 🤖 AI-powered code assistance
- 💻 Modern code editor
- 📁 Project management
- 🌙 Dark/Light mode support
- ⚡ Fast and responsive UI
- 🔍 Intelligent code suggestions
- 🛠️ Error detection and debugging support
- 📱 Responsive design

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/Kundank8789/ai-ide.git
```

### Navigate to Project

```bash
cd ai-ide
```

### Install Dependencies

```bash
npm install
```

### Create Environment Variables

Create a `.env.local` file:

```env
OPENAI_API_KEY=your_api_key
NEXT_PUBLIC_APP_URL=http://localhost:3000
```

---

## 🚀 Running Locally

Start development server:

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```
